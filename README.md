# 超勤ログ（PWA版）公開・利用ガイド

所定外時間（超勤）を記録し、月・3ヶ月・年間の上限までの残りを確認するアプリです。
記録は各自のスマホのブラウザ内にだけ保存され、サーバーには送信されません。

## 中身

| ファイル | 役割 |
|---|---|
| index.html | アプリ本体 |
| manifest.webmanifest | ホーム画面に追加するための情報 |
| sw.js | オフラインで起動するための仕組み |
| icons/ | アプリのアイコン |

## 1. GitHub Pages で公開する（無料・約10分）

1. GitHub にログインし、右上の「+」→「New repository」を選びます。
2. 名前は半角英数字で入力します（例：`choukin`）。公開設定は **Public** にして「Create repository」を押します。
   - 無料プランでは、Public のリポジトリだけが GitHub Pages で公開できます。
   - 置くのはアプリのファイルだけで、個人の記録は含まれません。
3. 作成後の画面で「uploading an existing file」を押します。
4. このフォルダの中身（`index.html`、`manifest.webmanifest`、`sw.js`、`icons` フォルダ）を、画面にドラッグ＆ドロップします。
   - `icons` フォルダごとドロップしてください。ZIPのままではなく、解凍した中身を入れます。
5. 「Commit changes」を押します。
6. 「Settings」→ 左メニューの「Pages」を開きます。
7. 「Build and deployment」の Source を「Deploy from a branch」にし、Branch を `main`、フォルダを `/ (root)` にして「Save」を押します。
8. 1〜2分待つと、画面の上部に公開アドレスが出ます。
   `https://（GitHubのユーザー名）.github.io/choukin/`
9. このアドレスを、使ってほしい人に送ります。HTTPS で配信されるので、そのままインストールできます。

## 2. スマホにインストールする（各自）

**iPhone**
1. Safari で公開アドレスを開きます。
2. 下の共有ボタン →「ホーム画面に追加」を押します。
3. ホーム画面のアイコンから起動します。

**Android**
1. Chrome で公開アドレスを開きます。
2. 右上のメニュー →「アプリをインストール」（または「ホーム画面に追加」）を押します。

インストール後の初回起動で、ブラウザ側の保存領域が別になる場合があります（特に iPhone）。
入力はインストール後に始めるか、先にバックアップを書き出して復元してください。

## 3. 最初の設定（各自）

画面右上の「設定」から、勤務形態、月の締め日、年度の最初の月度、上限時間などを合わせます。
初期値は、締め日20日、年度は4月度（3/21〜）、上限は月40h・3ヶ月180h・年360h です。
上限時間や休日は、各自が自分の分を変更できます。

### 休憩の入力ルール
実働（休憩を引いた時間）で、自動の休憩が決まります。

| 実働時間 | 自動で差し引く休憩 |
|---|---|
| 6時間以下 | なし |
| 6〜8時間 | 昼休憩 45分 |
| 8時間以上 | 昼休憩 45分 ＋ 定時後休憩 15分 |

- 自動の休憩は、入力画面の「休憩」欄に表示されます。その日だけ、✕で削除できます。
- 実際の休憩時間は、「＋ 休憩を追加（開始〜終了）」で、時刻を入力します。複数追加できます。
- 昼休憩と定時後休憩の分数は、「設定」で変更できます。
- 以前の方式（休憩を分数で入力）で保存した記録は、そのまま以前の計算で残ります。記録を開いて保存し直すと、新しいルールで計算し直します。

## 4. 記録の守り方（重要）

- 記録はそのスマホのブラウザ内だけにあります。機種変更、ブラウザのデータ消去（「Cookieとサイトデータ」を含む）、アプリの削除で消えます。
- 「設定」→「バックアップを書き出す」で、記録をファイルに保存できます。月末などに定期的に行ってください。30日以上とっていないと、画面に通知が出ます。
- 機種変更のときは、古いスマホでバックアップを書き出し、新しいスマホで「復元する」を押してファイルを選びます。
- 「CSVで書き出す」は、Excel などで集計するためのものです。復元には使えません。
- 公開アドレスを変えると、記録は新しいアドレスに引き継がれません。変えるときはバックアップで移してください。

## 5. アプリを更新するとき

1. GitHub のリポジトリで、更新したいファイルを開いて置き換えます（「Add file」→「Upload files」で上書きできます）。
2. アプリの仕組みを変えた場合は、`sw.js` の `VERSION = "v1"` を `"v2"` のように上げてください。
3. 利用者のスマホには、アプリを2回起動したあとに反映されます。

## 6. 社内サーバーに置く場合

GitHub の代わりに、社内の Web サーバーにも置けます（静的ファイルのみ・サーバー側の処理は不要）。
ただし、インストールとオフライン起動には **HTTPS** が必要です。社内発行の証明書を使う場合は、スマホにその証明書を入れてください。

## 7. うまくインストールできないとき

**Android で「インストール済み」と出るのに開かない（アンインストール後など）**
1. スマホの「設定」→「アプリ」で「超勤ログ」が残っていないか確認し、あれば削除します。ホーム画面のアイコンも消します。
2. Chrome を完全に終了します（アプリの履歴から上にスワイプして閉じる）。
3. もう一度 Chrome で公開アドレスを開き、メニューから「アプリをインストール」を選びます。
4. それでも出ない場合は、メニューの「ホーム画面に追加」で、ショートカットとして使えます。

**記録が消えてしまったとき**
アンインストールや、ブラウザのデータ消去で、記録が消えることがあります。
「設定」→「復元する」から、バックアップ（JSON）ファイルを読み込んでください。バックアップがない場合は、復元できません。

**Chrome のサイトデータを消して直す場合（最後の手段）**
Chrome の「設定」→「サイトの設定」→「すべてのサイト」で、公開アドレスのデータを削除します。**記録も消えるので、先にバックアップを書き出してください。** バックアップは、アプリではなく、Chrome の通常のタブで公開アドレスを開いて行えます。

**iPhone の場合**
Safari で公開アドレスを開き、共有ボタン →「ホーム画面に追加」を選びます。「インストール」の表示はありません。
